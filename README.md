GOLDEN TIDE — a complete 2D top-down open-world crime game set in Palmera, a sun-soaked golden-hour city. Play as Cole “Cash” Vega: walk the marina pier, steal six kinds of cars, outrun the Palmera PD through a 0–5 star wanted system, fight pier shootouts, and run four story missions plus taxi fares and five hidden cash stashes — all with a minimap HUD, a garage collection, localStorage saves, and fully synthesized WebAudio sound. No libraries, no network requests: plain static files that open in any desktop browser.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Controls: WASD move / drive · E enter or steal a car · Click / Space shoot · Shift run · P pause · M mute. Missions: M1 First Job (pier pickup → Mara's Garage, $150), M2 Sunset Steal (steal the orange convertible → Chop Shop, $300), M3 Pier Shootout (clear three gunmen → cash bag, $400), M4 Golden Getaway (beat the clock to the airport gate, $800).
